# Hi, I'm Juan Esteban Marín 👋

**Junior Full Stack / Backend Developer** · Cali, Colombia · Open to remote work

I'm a Systems Engineering student (graduating August 2027) and a software developer since November 2025. I build and run production systems for a printing company, used every day by around 25 people, from management to the shop floor.

## 🔧 What I'm working on

- **Perla**: a production-management and time-tracking system that replaced paper-based records, reducing manual-entry errors and giving managers real-time visibility of the shop floor. Built with ASP.NET Core (.NET 9), Entity Framework Core, PostgreSQL and a React Native (Expo) client for tablets and web.
- **Perlax**: a modular redesign of Perla built in parallel so production is never interrupted, with BCrypt authentication, brute-force lockout, audit logging, and work-order, technical-sheet and quotation modules.
- **Security & infrastructure**: Windows Server administration, Wazuh (SIEM), API hardening, and automated backups and deployments with PowerShell.

## 🚀 Featured project

**[AI Governance Evaluator](https://github.com/AIgobernance/Proyecto-Gestion)**: a university team project (6 developers) that lets companies assess the ethical and technical compliance of their AI systems and get a personalized improvement roadmap. I built the authentication and security layer (JWT activation, 2FA by SMTP and SMS, login lockout), the evaluation backend with n8n integration, and the React frontend.

`Laravel 12` `React 19` `SQL Server` `n8n` `Tailwind CSS`
